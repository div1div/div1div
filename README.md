## About me

I'm a C# developer based in Basra, Iraq, with a degree in accounting.
My accounting background shapes the way I build software, especially when
a workflow involves balances, transaction histories, or records that need
to be traced back to a user.

I build Windows desktop applications with WinForms, ADO.NET, and SQL Server.
I'm open to Junior .NET and C# desktop developer roles across Iraq.

## Projects

### Bank Management System

A desktop banking simulation that follows an account from its first deposit
through withdrawals, transfers, and financial reporting.

- Manage client profiles and search account records.
- Validate balances before withdrawals and transfers.
- Trace account activity through transaction history, date-range reports, and charts.

**Built with** C#, WinForms, ADO.NET, SQL Server, and three-tier architecture.

[View the bank project on GitHub →](https://github.com/div1div/Bank-Managment-System)

### Private School Management System · In development

An Arabic-language desktop application for Iraqi private schools. Staff can
manage student records, employees, departments, academic years, and user accounts.

- Search and filter records from Arabic WinForms screens.
- Track who created, updated, or soft-deleted a record.
- Keep SQL operations in stored procedures, with separate UI, business, and data-access layers.

**Built with** C#, .NET Framework 4.8, WinForms, ADO.NET, SQL Server, and T-SQL.

### Iraqi Electricity Bill Calculator

An Arabic web calculator that estimates an electricity bill in Iraqi dinars.
Enter the previous and current meter readings, then select the customer category
to see consumption and the estimated charge.

**Built with** HTML, CSS, and JavaScript.
